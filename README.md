I got sick of manually constructing reference shit for Minimax H3 Ref2VA, so I wrote this plugin to split the different prompt sections up (subject_definitions, retention_analysis, etc.), dynamically detects when you add a reference to bring up a toolbar to one-click insert them, adds inline badges to inserted references with previews on hover, constructs template builds, etc.
