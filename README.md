I got sick of manually constructing reference shit for Minimax H3 Ref2VA, so I wrote this plugin to dynamically detect what references you have attached and then 1 click to insert them.
This plugin splits the different sections up, detects when you add a reference to bring up a toolbar to one-click insert them, constructs template builds, etc.
